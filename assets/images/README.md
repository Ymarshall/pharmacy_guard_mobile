# Images

`logo.png` est le logo de marque de l'application (pin aux couleurs de
la Côte d'Ivoire, croix de pharmacie et étoile), le même motif que
l'écran de démarrage.

- `logo.png` — fond vert forêt `#184F2E`, pour l'icône classique / ronde
- `logo_foreground.png` — disque blanc sur fond transparent, pour l'icône
  adaptative Android (zone sûre 72/108)

Régénération : `python3 tool/export_app_logo.py` (Pillow requis).
